# Accessibility

Target WCAG 2.2 AA. Foundations include skip navigation, landmarks, visible focus, keyboard menus/dialogs, focus return, native scrolling, reduced motion, semantic forms/status, tabs, filters, disclosures, and SVG alternatives.

Before launch, test 320, 375, 768, 1024, and 1440px; keyboard; VoiceOver/NVDA; 200% zoom; final-image contrast; real Arabic RTL; provider errors; and facility access. Final media needs approved alternatives and captions where relevant.
