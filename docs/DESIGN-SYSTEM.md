# Design System

Restrained neo-brutalism uses near-black surfaces, warm-white text, orange accent, thick rules, sharp corners, hard shadows, condensed display type, and asymmetrical editorial layouts. Tokens live in `app/globals.css`.

Use `.container`, `.section`, `.display`, `.eyebrow`, and `.button` deliberately. Avoid card monotony, decorative SaaS gradients, glass effects, and excessive motion. Controls need 48px targets and visible focus. Reduced motion disables transitions and smooth scrolling.
